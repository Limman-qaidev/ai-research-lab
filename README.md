# Artificial Intelligence Research Lab

A long-term personal research and learning laboratory for understanding artificial intelligence from first principles and building progressively more capable systems involving agents, learning, search, evolution, competition, cooperation, evaluation, and automated discovery.

## This repository is the source of truth

Chats, assistants, notebooks, and temporary working sessions are **not** the authoritative memory of this project. The repository is.

Before any new AI-assisted session, read in this order:

1. `AGENTS.md`
2. `docs/00_project/PROJECT_CHARTER.md`
3. `docs/00_project/LEARNING_CONTRACT.md`
4. `docs/00_project/ROADMAP.md`
5. `docs/00_project/CURRENT_STATE.md`
6. Any decision records and experiment documents referenced by `CURRENT_STATE.md`

A ready-to-use bootstrap prompt is kept at `docs/99_handoff/CHAT_BOOTSTRAP.md`.

## Core principle

The purpose of the project is **not** to accumulate code or assemble fashionable LLM frameworks. The purpose is to understand, derive, implement, test, and experimentally study the mechanisms that make intelligent systems work.

The learning sequence is intentionally progressive:

`game theory and evolution -> single-agent RL -> self-play -> multi-agent RL -> population methods -> search/planning -> automated discovery -> LLM-guided discovery`
