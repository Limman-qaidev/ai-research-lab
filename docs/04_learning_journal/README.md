# Learning Journal

This directory records Jonathan’s **learning state**, not the project state.

Use it to capture:

- ideas that finally became clear;
- concepts that remain fuzzy;
- derivations that had to be reconstructed several times;
- misconceptions or false intuitions discovered;
- connections between apparently separate topics;
- moments when a library/API was being used mechanically;
- questions worth revisiting later;
- evidence that a concept has become independently usable.

Do not turn the journal into a chronological activity log.

## Suggested cadence

Write only when something meaningful changes in understanding. One concise entry after an important session is usually more useful than daily bookkeeping.

Use `JOURNAL_TEMPLATE.md` as a loose guide, not a mandatory form.
